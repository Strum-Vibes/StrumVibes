# StrumVibes 

StrumVibes is a live guitar-learning platform website built to present guitar classes, courses, and student enquiry options through a custom web experience.

🌐 **Live Website:** https://strumvibes.in  
💻 **Repository:** https://github.com/Strum-Vibes/StrumVibes

## About the Project

StrumVibes was designed and developed as the online presence for my guitar-learning platform. The project focuses on a clean, premium visual identity while providing visitors with information about the platform, available courses, and an enquiry form.

The website is currently live and continues to be improved, particularly in terms of responsiveness, UI refinement, and overall user experience.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git & GitHub

## Pages

- **Home** — Hero section, platform information, features, course highlights, and enquiry form
- **About** — Information about StrumVibes and its approach to guitar learning
- **Courses** — Course information with interactive course-detail sections
- **Privacy Policy** — Privacy and website information

## Key Features

- Custom gold, teal, and dark visual theme
- Multi-page website structure
- Responsive layout work in progress
- Scroll-based reveal animations
- Intersection Observer based animations
- Interactive course-detail accordion
- Guitar course enquiry form
- Form submission handling with JavaScript and a Google Apps Script endpoint
- Live deployment with custom domain
- Source code maintained using GitHub

## Project Status

**Ongoing**

The website is already deployed and functional, while development continues with a focus on:

- Improving mobile and tablet responsiveness
- Refining UI and visual consistency
- Improving animations and interactions
- Enhancing the overall user experience
